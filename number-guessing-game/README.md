# Java Number Guessing Game

## About
A simple console-based number guessing game developed using Java. The player tries to guess a randomly generated number.

## Features
- Generates a random number.
- Accepts guesses from the player.
- Provides hints to guess higher or lower.
- Continues until the correct number is guessed.

## Technologies Used
- Java
- Java Standard Library

## How to Run
1. Make sure Java JDK is installed.
2. Open a terminal in this folder.
3. Compile the Java file:

   `javac pr_1_number_guess.java`

4. Run the compiled program:

   `java pr_1_number_guess`
